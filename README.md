# AFTERLIGHT

Playable apocalypse survival sandbox, version 0.2.

Travel diagonally or select a revealed destination to preview a multi-district journey. Grow from Holdout through Outpost, Settlement, Stronghold and Haven without losing earlier upgrades. Use the Recruitment desk in Survivors or Settlement to organize a search or explicitly call for survivors by radio.

Export your save before upgrading or changing devices. Valid older saves migrate with existing progress preserved; v0.2 saves do not load in v0.1. Recruitment deadlines use game hours advanced by actions, not real-world waiting. Browser storage is local to this site and device.

This repository contains playable runtime and hosting files only. The versioned v02 assets avoid mixing new scripts with cached older ones. Earlier root assets are retained for already-cached pages. No accounts, external services or telemetry are required.
